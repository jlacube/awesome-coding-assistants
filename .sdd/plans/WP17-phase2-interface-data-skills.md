## Objective

Implement two Phase 2 contract generation skills: `plan-interface-contracts` (public function/method signatures, class/module interfaces) and `plan-data-schemas` (entity type definitions, validation rules, relationships). These skills read the plan accumulator from Phase 1 and generate language-specific contract files scoped per WP.

## Spec References

FR-037 through FR-042, Section 4.5, Section 4.6, Section 7.2 (Contract Files data model)

## Implementation Notes

- Both skills are Phase 2 and read the plan accumulator produced by Phase 1 (WP16)
- They produce language-specific source files, not markdown
- Contract files must be valid syntax in the target language
- The 800-line block limit (FR-013) is a skill-level concern -- the coordinator does not enforce it

## Parallel Opportunities

- T17-01 through T17-04 (interface contracts) can be worked in parallel with T17-05 through T17-07 (data schemas) since they are independent skills
- WP17 as a whole can be parallelized with WP18 and WP19 after WP14 and WP15 complete

## Risks & Mitigations

- **Risk**: Spec companion artifacts may not exist for all projects. **Mitigation**: Skills must handle the "no artifact" case gracefully, generating contracts from spec prose.
- **Risk**: Entity deduplication (FR-042) requires processing WPs in order. **Mitigation**: The skill scans all WPs first to build an entity-to-WP mapping before generating any contracts.
